Exit codes, inspect templates, and how to add a recipe

Container exit codes

The number after Exited (…) in docker ps -a. Anything ≥ 128 is a signal: subtract 128.

CodeMeaningUsually
0clean exita one-shot job that finished (migrations, init containers); a server that was asked to stop
1the application failedread the last 50 log lines: config, credentials, a dependency not reachable
125the daemon refused to run itbad flag, port already allocated, mount path missing
126command found but not executablean entrypoint script without +x, or a directory
127command not foundwrong ENTRYPOINT/CMD, missing shell, CRLF line endings in a script
137SIGKILL (9)OOM killer (.State.OOMKilled), docker kill, or a stop timeout that expired
139SIGSEGV (11)the binary crashed: wrong architecture image, a native module mismatch
143SIGTERM (15)a normal docker stop; only a problem if nobody asked for it

docker inspect templates worth memorising

Go templates over the container's JSON. -f is --format; {{json .X}} dumps a subtree; range walks a list.

docker inspect -f '{{.State.Status}} exit={{.State.ExitCode}} oom={{.State.OOMKilled}} restarts={{.RestartCount}}' NAME
docker inspect -f '{{json .State.Health}}' NAME | python3 -m json.tool
docker inspect -f '{{range .Config.Env}}{{println .}}{{end}}' NAME
docker inspect -f '{{range .Mounts}}{{.Type}} {{.Name}}{{.Source}} -> {{.Destination}}{{println}}{{end}}' NAME
docker inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}} {{end}}' NAME
docker inspect -f '{{.Config.Image}} {{.Image}}' NAME
docker inspect -f '{{.State.Pid}}' NAME
docker inspect -f '{{.HostConfig.RestartPolicy.Name}}' NAME

Maintaining this page

One file, no build step. The recipes are the JSON array in <script id="data-recipes"> near the end of the file; the symptom paths are in <script id="data-symptoms">.

  • Add a recipe: append one object { id, cat, title, why, tags, steps:[{cmd, note}], read, grobase }. id must be unique (it is the anchor); cat must be one of the category keys listed in CATS. grobase is optional.
  • Add a symptom: { id, title, hint, path:[recipe ids…] }. Order matters: it is the order to check things.
  • Commands are plain text: never put </script in one. HTML is escaped on render; `…` in prose becomes <code>.
  • Open the file in a browser after editing; a JSON typo shows as an error banner at the top instead of the recipes.
